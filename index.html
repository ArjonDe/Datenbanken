SQL-Tutorial (Für absolute Anfänger)

Was ist eine Datenbank?

Stell dir eine Datenbank wie einen riesigen, extrem gut organisierten Aktenschrank vor. In diesem Schrank gibt es Mappen (Tabellen). Jede Mappe enthält Zettel (Datensätze/Zeilen), auf denen Informationen nach einem festen Raster (Spalten/Attribute) aufgeschrieben sind[cite: 24, 25].

Was ist SQL?

SQL (Structured Query Language) ist die Sprache, mit der du dem Aktenschrank Befehle gibst. SQL ist eine deklarative Sprache: Du sagst dem System was du haben willst, nicht wie es das holen soll[cite: 26].

Die 4 wichtigsten Befehle (CRUD)[cite: 30, 131]

  • CREATE / INSERT: Neue Daten anlegen. (Beispiel: Lege einen neuen Zettel in die Mappe.)
  • READ / SELECT: Daten auslesen. (Beispiel: Zeige mir alle Zettel, auf denen "Hagen" steht.)
  • UPDATE: Daten ändern. (Beispiel: Ändere die Adresse auf dem Zettel von Max.)
  • DELETE: Daten löschen. (Beispiel: Wirf den Zettel von Max weg.)

Der wichtigste Befehl: SELECT[cite: 33]

Die Struktur einer Abfrage sieht immer so aus:

SELECT [Was will ich sehen? z.B. Spaltennamen oder * für alles]
FROM [Aus welcher Tabelle?]
WHERE [Unter welcher Bedingung? z.B. alter > 18];

Datenmodellierung & Normalisierung

Entity-Relationship-Diagramme (Chen-Notation)[cite: 71, 72]

Die Chen-Notation nutzt bestimmte Symbole, um die Realität abzubilden:

Kunde (Entität)
1
besitzt
N
Konto (Entität)
  • Rechteck (Entitätstyp): Ein Objekt der realen Welt (z.B. Kunde, Konto).
  • Raute (Beziehung): Der Zusammenhang zwischen Entitäten (z.B. besitzt).
  • Kardinalitäten (1, C, M, N): Wie viele Entitäten miteinander in Beziehung stehen können/müssen.

Ableitungsregeln (ERM zu Tabellen)[cite: 79, 81]

  • 1:N Beziehung: Ein Fremdschlüssel kommt immer in die N-Seite. (Beispiel oben: Das Konto bekommt die Kunden_ID als Fremdschlüssel).
  • M:N Beziehung: Muss zwingend durch eine dritte Tabelle (Beziehungstabelle) aufgelöst werden. Diese enthält die Primärschlüssel beider Grundtabellen als Fremdschlüssel.

Die Normalformen[cite: 99, 100, 101]

Normalform Regel (Kurzfassung)
1NF Atomare Werte. Keine Tabellen oder Listen innerhalb einer Zelle.
2NF 1NF erfüllt + Nichtschlüsselattribute hängen vom *gesamten* Primärschlüssel ab.
3NF 2NF erfüllt + Keine transitiven (indirekten) Abhängigkeiten zwischen Nichtschlüsselattributen.
4NF 3NF erfüllt + Keine Attribute, die sich aus anderen ableiten/berechnen lassen (z.B. Bruttopreis aus Netto + Steuer).
